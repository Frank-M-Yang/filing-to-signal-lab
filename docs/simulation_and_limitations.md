# 模拟校准与限制

## 偏差如何进入数据

模拟器首先生成原始财报，再生成每日市场与个股收益。原始信号只获得很弱的后公告漂移。
三种偏差通过独立机制加入：

1. 一部分重述调整与已经实现的未来收益带有弱相关；在历史上使用这些重述值会泄露未来。
2. 最终退市公司的末期财报制造容易误导的正信号，同时价格承受压力；只保留存续公司会
   删除这些失败观察。
3. 信号相关的价格反应发生在公告收盘后到第二个交易日开盘之间；假设公告收盘成交会
   捕获无偏策略无法获得的回报。

相关强度由 `SimulationConfig` 的命名参数控制，并用固定种子保持可复现。默认目标是让
全部偏差情景约为 15% 年化、全部修正情景低于 3%。这是产品验收校准，而非拟合真实数据。

## 不能从本项目推断什么

- 不能推断 SUE 或毛利率变化在真实市场的预期收益；
- 不能把偏差影响的模拟幅度当作经验估计；
- 不能声称因果关系或可实施的投资策略；
- 不能忽略真实数据适配器中的点时版本、历史股票池、退市收益和交易所时间戳问题。
