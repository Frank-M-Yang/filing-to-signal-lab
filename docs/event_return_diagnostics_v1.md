# 真实事件收益诊断 v1.1

## 研究边界

这一轮不是财报信号回测，而是对第一版真实事件收益账本做三个可证伪的诊断：

1. 28 个公司事件的 20 个交易日总收益是否与同期 SPY 有明显差异；
2. 如果使用事后退市状态，只保留结果截止日仍活跃的证券，样本统计量会被改变多少；
3. 这 28 个收益事件能否与现有 Level / Delta / Innovation 财务表示做严格同事件连接。

事件执行规则沿用冻结的收益账本：SEC `accepted_at` 之后第二个正式交易日，以未调整
regular-session open 进入；持有 20 个正式交易日，以未调整 close 退出。拆股改变持股数，
现金分红保留但不再投资。市场超额收益为公司总收益减同期 SPY 总收益。

## 冻结输入

- 收益账本：`event-return-ledger-v1-7b824e392f85232e`
- 价格就绪审计：`sec-price-readiness-v6-9e06c6d4b248e770`
- 财务表示：`pilot-filing-features-v1.1-b8c407284c843d77`
- 诊断版本：`event-return-diagnostics-v1.1-5b36a5d207073714`

所有输入通过 `output_manifest.json` 的 SHA-256 绑定。诊断不会用当前 ticker 或当前公司
状态替换历史证券身份，也不会把缺失退市回报填成零。

## 结果

| 样本 | 事件数 | 平均公司收益 | 平均 SPY 收益 | 平均市场超额 | 中位市场超额 | 跑赢 SPY |
|---|---:|---:|---:|---:|---:|---:|
| 全部事件 | 28 | -5.13% | -4.10% | -1.04% | -1.75% | 9 / 28 |
| 只保留结果截止日仍活跃 | 25 | — | — | +0.72% | -1.62% | — |
| 正式退出后后来退市 | 3 | — | — | -15.70% | — | — |

用未来退市状态删除 DNB、ASNS 和 ISPO 后，平均市场超额收益从 -1.04% 变为 +0.72%，
被抬高 1.76 个百分点；但中位数只被抬高 0.13 个百分点。这个差异主要来自 ASNS 和
ISPO 的负尾部，而不是整个分布均匀移动。

三只证券都是在正式 20 日退出窗口之后才退市。它们的窗口收益本身是完整观察值；把它们
删掉不会“修复”数据，反而是在样本选择中使用未来信息。因此，这个结果是幸存者偏差的
机制演示，不是退市公司总体回报的估计。

## Level / Delta / Innovation 连接闸门

严格连接键是同一个 filing accession，并要求财务表示的 `actual_available_at` 与价格样本
中的 SEC `accepted_at` 完全一致。结果为：

- 公司重叠：28 / 28；
- accession 与 `accepted_at` 精确重叠：28 / 28；
- Level：15 / 28；
- Delta：13 / 28；
- 原始及标准化 OOS Innovation：11 / 28；
- Level / Delta / Innovation 完整同事件样本：11 / 28；
- 探索性 IC：禁止计算。

连接问题已经解决，当前瓶颈是可比财务概念与历史深度。13个事件没有严格季度毛利率，
2个有 Level 但没有同比基期，另2个有 Delta 但尚无满足训练门槛的样本外预测。系统保留
这些事件及失败原因，不填零，也不从28事件母样本中删除。

只有达到至少20个完整事件且覆盖率不低于80%（28个事件中至少23个），第一版探索性
Spearman IC才会解锁。当前11个完整事件同时不满足两个条件；即使未来解锁，也不允许
把这个小型 pilot 当作信号有效性的最终结论。

## 可视化与复现

Streamlit 侧边栏选择“成果 05 · 真实事件收益诊断”，可以查看：

- 28 个事件按市场超额收益排序；
- 公司收益与同期 SPY 的散点比较；
- 全样本与故意 survivors-only 样本的均值差异；
- 收益、退市结果、行业基准和财务表示连接闸门。

复现命令：

```powershell
uv run python -m scripts.build_event_return_diagnostics
uv run streamlit run app.py
```

输出位于 `data/processed/event_return_diagnostics/`，包含逐事件诊断、幸存者偏差反事实、
表单分组、严格特征连接审计、IC 闸门和完整 manifest。

## 仍未解决

- 28 个事件不是全市场代表样本，不能估计信号收益、退市发生率或市场总体均值；
- 事件窗口集中在 2024–2025 年并且相互重叠，不能把事件均值年化或计算组合夏普；
- 历史点时行业映射和行业基准仍未接入；
- Level / Delta / Innovation 共同样本只有 11 / 28，IC 闸门未通过；
- 没有交易成本、成交量容量、借券约束或组合构建。

因此 v1.1 的正面成果是：真实收益与真实 PIT 财务特征已在同一事件上接通；同时系统在
覆盖不足时仍主动拒绝生成漂亮但统计上无效的信号图。
