# 一致预期替代源：固定小样本验收 v1

本轮只准备数据源可行性试验。**请求包已生成，真实供应商样例尚未取得，验收尚未完成。**
没有注册账号、提交表单、发送邮件、申请订阅或付款；没有改变原 37 个研究事件。

## 固定样本

前六家公司来自已冻结的原 20 家采集计划前六名；后四家是已经识别的口径或财季
难例。公司不会因某供应商缺数据而替换。这个选择用于测试接口与定义，不是随机样本，
也没有验证退市覆盖或消除幸存者偏差。

每家使用指定 SEC submissions 快照中、2026-08-01 00:00 UTC 前接受的最近两个
不同报告期的原始 10-Q。忽略修正表单；同报告期有多个原始条目时选最早接受的。
这是**固定缓存中的两个可用 10-Q 报告期**，不保证是连续季度或今天全量目录中
最新的两个季度。没有用收益、财报实际收入或供应商样例来选择。

| 公司 | 两个 SEC 报告期末 | 纳入原因 |
| --- | --- | --- |
| AMZN | 2026-06-30、2026-03-31 | 原计划第 1 位 |
| WMT | 2026-04-30、2025-10-31 | 原计划第 2 位 |
| UNH | 2026-03-31、2025-09-30 | 原计划第 3 位 |
| AAPL | 2026-06-27、2026-03-28 | 原计划第 4 位，周制财季 |
| MCK | 2025-12-31、2025-09-30 | 原计划第 5 位 |
| GOOGL | 2026-06-30、2026-03-31 | 原计划第 6 位，需核对公司/股份类别映射 |
| PSX | 2026-03-31、2025-09-30 | 收入口径核验 |
| MPC | 2026-03-31、2025-09-30 | 收入口径核验 |

| DELL | 2026-05-01、2025-10-31 | 周制财季与供应商月末标签映射 |

每季度请求 **季末前 30 天、7 天的 UTC 23:59:59** 两个历史视角，取得不晚于该时刻
的最近一个原生 PIT 快照，保留原生时区、日期精度和数据年龄。可能遇到周末，不能
用之后的快照填补。共 **20 个季度 × 2 个视角 = 每家供应商 40 个请求位置**；
这是数据交付位置数量，不承诺 API 调用次数。

例如 DELL 2026-05-01 季度，两个请求视角为 2026-04-01 和 2026-04-24 的上述 UTC 时刻。
供应商必须说明这些视角下，该季度应对应其哪个 fiscal period；不能就近猜日期。

本轮故意先检验历史版本恢复，不声称恢复“公告前一刻市场预期”。10-Q acceptance
仅是报告期来源记录，**不当作首次业绩公告时间或交易 cutoff**。若样例通过，再做
更小的、带已核实首次公告时间的边界试验；两项不能合并成一个自动通过的结论。

## 验收顺序：先证据，后覆盖，再谈研究

1. **许可与原始材料**：明确允许本地研究的授权范围，拿到原生文件/响应和字段字典；
   先保存字节、哈希、提取时间与查询参数。没有权限的资料不作为可用样例。
2. **身份与财季**：核对 CIK、供应商 ID、公司与股份类别，以及精确季度期间；
   不用年度预测补季度，不自动把月末标签改成最近周五。
3. **币种、倍数和口径**：预测均值与实际值的定义必须能对齐。有无法对齐的公司，
   逐项拒绝或待查，不因金额看着接近就认定一致。
4. **历史版本与时间**：核实视角时区、精度、激活/修正机制，以及该版本在请求
   视角下是否可得。日级 PIT 可以支持适当的低频研究，不必苛求分钟级数据；
   但不得把日级日期伪装成精确的分析师发布时间。
5. **统计定义**：先看普通共识均值；FactSet 请求默认窗口并说明具体方法，
   不先选 Sharp；LSEG 不先选 SmartEstimate。记录人数、权重、预测纳入窗口及
   陈旧预测处理。两个供应商均值不同，不自动判定其中一个错误。
6. **同样本覆盖**：每家都以固定 40 个位置为分母，列出缺失、拒绝、待查。
   只在两家都满足可比定义的相同位置对照数值；不按收益表现选择供应商。

分析师 ID 对个体修订研究有帮助，但**不是验证聚合 PIT 共识的必需字段**。
我们需要可靠的聚合快照和方法定义，不是无限扩充数据要求。

未取得数据记作 `not_tested`，不能计作供应商测试失败。基础检查通过也只表示适合
进一步研究，不自动批准迁移、入模、采购或交易。正式准入仍使用独立研究协议。

## 复现与下一步

```powershell
uv run python -m scripts.build_consensus_source_trial
```

配置：`docs/consensus_source_trial_v1.json`。
当前输出：`data/processed/consensus_source_trial/consensus-source-trial-v1-cf31c55bd0f0a2d2.json`。
该输出含 40 个稳定 request ID、每个历史视角、报告期、来源 accession 和哈希。
命令不联网、不使用密钥；需要现有本地缓存。公开克隆不含私有缓存，可运行
`tests/test_consensus_source_trial.py` 的合成测试，但不能声称复现了真实供应商结果。

已准备[两家通用的样例申请草稿](consensus_source_sample_request_draft.md)。
下一步需要现有合法数据权限，或另行批准联系供应商获取样例。
没有权限时，不试猜 API、不购买套餐、不拿实时数据伪装历史样例。
