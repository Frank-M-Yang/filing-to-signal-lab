# 收入预测定义与更新时间审计

审计日期：2026-09-19 UTC（布鲁塞尔为 9 月 20 日）。
本轮为只读证据审计，不调整模型、不注册新事件、不更改冻结交易政策。

## 结论

**缺口不是 DELL 独有：当前缓存能证明我们何时取得供应商响应，但不能完整证明
这些收入预测的计量口径、新鲜程度或分析师修订时点。**
这不意味着所有数字都是错误的，也不使已经保存的抓取时间失去价值。
它限制的是我们可以据此作出的经济解释。

## 对现有研究意味着什么？

1. **可保留的证据**：某次真实抓取时，接口确实返回这些原始字节。数值变化仍可
   描述为“供应商快照变化”。不回填成更早时间，不伪造公告前预测。
2. **尚不能升级的解释**：不能仅凭抓取时钟，就声称这些变化是市场刚获知的新信息；
   也不能未经定义确认就直接与 SEC 实际收入计算同口径超预期。
3. **现有 `clean` 的边界**：它指既有质量规则通过，不等于供应商定义、更新时间、
   实际值映射和可交易性都已验证。原标签和注册表不追溯改写。
4. **不必过度否定**：缺少分析师修订时刻，不必然导致未来信息泄漏。若未来另行
   冻结研究“在抓取时可获得的供应商预测”的表现，这是不同、可以明确描述的
   研究对象；但仍需要单位/口径和实际值可得时点正确。不能把它包装成全市场
   最新预期，也不能通过放宽原规则获得更好结果。
