# 研究方法

## 信息集

无偏情景只读取 `eps`、`revenue` 和 `gross_margin` 原始披露列。重述列代表公告后若干
交易日才可见的修订版本，因此只有主动打开前视偏差时才进入信号计算。信号的同比基准
使用四季度滞后，SUE 的波动率使用当前期之前八个季度，避免当前观察值污染标准差。

## 横截面与执行

每个 `report_date` 是一个排名批次。公司可以在不同日期公告；其成交价分别取自身
公告日对应的执行时点。无偏执行使用公告日之后第二个工作日开盘价，偏差执行使用公告日
收盘价。退出价是入场后第 N 个工作日收盘价。

信号最高和最低的分位数组成多空组合。两侧各占 50% 资金，因此组合净市场敞口为零。
个股同期收益减去模拟基准收益，用于 IC 与分位数组合统计。由于同一批次的多空权重和为
零，基准项在多空收益中相消，但保留它能让单边分位数的含义明确。

## 指标

- 年化收益：季度批次收益的几何复利，按每年四期折算；
- 夏普比率：季度收益均值除以标准差，再乘 `sqrt(4)`，无风险利率设为零；
- 最大回撤：累计净值相对历史峰值的最大跌幅；
- IC：每季度信号排名与未来超额收益排名的 Pearson 相关，即 Spearman 相关；
- 分位数收益：每个信号五分位的平均 20 日超额收益。

所有指标描述模拟样本，不包含统计显著性或真实可交易性结论。
