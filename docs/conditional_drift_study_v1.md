# Conditional Drift Study v1

Status: frozen historical-development protocol and first diagnostic, 2026-08-29.

## Question

The study asks a narrower question than “can filings predict returns?”:

> Conditional on the pre-filing state and the accounting innovation, does the market's
> observable reaction before a realistic entry contain information about subsequent drift after
> explicit execution costs?

The atomic row is **Company × Filing Event × Information Set**. State, Delta, Innovation,
Reaction, and every return label are compared on the same complete-case events. This study does
not authorize a trading strategy or an investment recommendation.

## Frozen clocks

- `accepted_at`: SEC acceptance timestamp; the disclosed accounting information is not available
  earlier.
- State cutoff: the last completed market session before `accepted_at`.
- Reaction reference: the last regular close at or before acceptance.
- Reaction availability: the last completed regular close before the formal entry.
- Formal entry: unadjusted regular-session open on the second trading session specified by the
  audited event calendar.
- Exit: unadjusted regular-session close on holding session 5, 20, or 60, counting the entry
  session as session one.
- Training eligibility: a training label's exit timestamp must be **strictly earlier** than the
  test event's reaction-feature availability timestamp.

The reaction window therefore cannot use the entry open or any later observation. Corporate
actions use the existing split-adjusted-share, cash-dividend-retained convention. Market-excess
returns use SPY over the exact same entry and exit sessions.

## Feature families

State contains the originally reported gross-margin level, form indicator, and strictly prior
issuer/market momentum, volatility, volume, relative momentum, and beta. Delta remains an
explicit comparator and is never renamed Innovation. Innovation contains raw and standardized
gross-margin forecast errors; the latter uses only earlier out-of-sample forecast errors.
Reaction contains pre-entry market-excess return, reaction volume relative to 20 strictly prior
sessions, and the number of completed reaction sessions.

Seven fixed Ridge baselines are run: zero, State, Delta, Innovation, Reaction,
State+Delta+Innovation, and the full State+Delta+Innovation+Reaction specification. Ridge alpha is
10 and is not tuned. Forecasts are generated by an expanding, label-maturity-aware simulation.

## Cost convention

The study reports gross market-excess returns and three explicit round-trip deductions:

| Scenario | Round-trip deduction |
|---|---:|
| Low | 10 bps |
| Base | 25 bps |
| Stress | 50 bps |

These are transparent sensitivity calibrations, not measured bid/ask spreads, market impact,
borrow fees, futures roll costs, or a broker quotation. The base 25 bps net label is used for the
development regression.

## First historical-development result

The immutable bundle `conditional-drift-study-v1-308193822964b064` contains 58 filing events from
15 issuers. Thirty-five events have the full same-event State/Delta/Innovation/Reaction vector.
All 35 have 5- and 20-session labels; 21 events from 13 issuers have a mature 60-session label.
The data, issuer-breadth, 60-session-coverage, and point-in-time development-prediction gates pass.

Only 17 events receive a 5-session development prediction and 14 receive a 20-session prediction,
because earlier events are reserved to provide already-matured training labels. No 60-session
model metric is emitted: the available 60-session history does not meet the frozen training gate
before the later prediction clocks.

Selected descriptive rank correlations are:

| Fixed model | 5 sessions | 20 sessions |
|---|---:|---:|
| State | +0.676 | +0.226 |
| Delta | -0.306 | -0.068 |
| Innovation | +0.032 | +0.349 |
| Reaction | +0.051 | +0.380 |
| Full | +0.564 | +0.134 |

These values are **not validation statistics**. All outcomes were already part of the historical
development environment before this protocol was frozen, sample sizes are tiny, multiple fixed
views are shown, and no uncertainty interval is claimed. The useful observation is diagnostic:
the feature blocks are no longer mere aliases, and Reaction/Innovation can rank later 20-session
outcomes differently, while naively combining every input does not improve the rank correlation.
That is a reason to preserve simple baselines—not evidence to select the best-looking column.

Across the 35 complete events, the unconditional mean market-excess return is -0.015% at five
sessions and -0.830% at 20 sessions. Deducting 25 bps changes those means to -0.265% and -1.080%.
The 21 mature 60-session events average -10.331% gross and -10.581% after the base deduction. This
is an issuer- and calendar-specific historical slice, not a portfolio P&L estimate; the negative
60-session value especially requires a larger, outcome-blind sample before interpretation.

## Honest verdict and next gate

The frozen verdict is:

`development_diagnostic_only_external_validation_required`

The unobserved-external-validation and live-trading gates remain closed. The next valid evidence
must come from events whose roles were frozen before their returns were collected, followed by
issuer-clustered uncertainty, cost/turnover measurement, and a portfolio construction protocol
that is also frozen before evaluation. Until then this result can guide data collection and model
simplification, but not capital allocation.
